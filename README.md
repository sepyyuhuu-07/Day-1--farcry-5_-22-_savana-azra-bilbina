Rangkuman Materi Workshop
1. Prompt Engineering
Prompt Engineering adalah cara menyusun instruksi supaya AI bisa memberikan hasil yang sesuai dengan kebutuhan. Prompt sendiri merupakan pertanyaan atau perintah yang kita berikan kepada AI.
Saat membuat prompt, kita perlu memberikan konteks yang jelas. Dalam materi workshop, ada empat bagian yang bisa digunakan untuk menyusun prompt: - Role: peran yang diminta dari AI. - Task: tugas yang harus dikerjakan. - Context: informasi atau latar belakang yang dibutuhkan. - Format: bentuk jawaban yang diinginkan.
Contoh yang dibahas adalah membuat aplikasi sederhana bernama Student Task Planner. Aplikasi ini membantu mahasiswa mencatat tugas dan tenggat waktu. Dari contoh tersebut, prompt perlu menjelaskan tujuan aplikasi, fitur yang dibutuhkan, batasan, dan hasil yang ingin diberikan.
Materi juga menjelaskan bahwa prompt yang disusun dengan baik dapat membantu meningkatkan hasil AI, membuat jawaban lebih terarah, dan memberi pengguna kontrol yang lebih baik.
2. Mengenal Git
Git adalah alat untuk mencatat dan melacak perubahan pada file atau proyek. Dengan Git, kita bisa melihat perubahan yang dilakukan selama proses pengerjaan.
Dalam Git Workflow, ada tiga bagian yang dijelaskan: - Working directory: tempat kita membuka dan mengubah file proyek. - Staging area: tempat menyiapkan perubahan yang akan disimpan. - Git directory: tempat Git menyimpan informasi dan riwayat proyek.
3. Perbedaan Git dan GitHub
Git dan GitHub saling berhubungan, tetapi keduanya berbeda. - Git digunakan untuk melacak perubahan proyek di komputer. - GitHub merupakan platform online untuk menyimpan repository Git dan membantu kolaborasi.
Jadi, Git membantu mengatur riwayat perubahan, sedangkan GitHub menjadi tempat menyimpan proyek secara online.
4. Perintah Dasar
Beberapa perintah yang diperkenalkan selama workshop adalah:
Perintah                            Fungsi
git init                          Membuat atau memulai repository Git.
git add .                         Menyiapkan perubahan file ke staging area.
git commit -m "message"           Menyimpan perubahan dengan pesan commit.
git remote add <name> <url>       Menambahkan alamat repository online.
git push origin main              Mengirim perubahan ke GitHub.
git pull origin main              Mengambil perubahan dari repository online dan menggabungkannya ke branch aktif.
git clone "url"                   Menyalin repository dari alamat yang diberikan.
5. Persiapan Git dan VS Code
Sebelum menggunakan Git, kita perlu menginstalnya sesuai perangkat yang digunakan. Setelah itu, instalasi bisa diperiksa melalui terminal dengan perintah git --version.
Materi juga menjelaskan cara mengatur nama dan email pengguna Git menggunakan: - git config --global user.name "Your Name" - git config --global user.email "your-email@example.com"
Untuk memeriksa pengaturannya, gunakan git config --global --list. Selain Git, workshop juga memperkenalkan Visual Studio Code (VS Code) sebagai editor kode.
6. Menghubungkan Proyek ke GitHub
Proyek bisa dimulai dengan membuat repository Git menggunakan git init. Cara lainnya adalah membuat repository di GitHub, menyalin alamatnya, lalu menggunakan perintah git clone "url" di terminal.
Pada materi ini juga diperkenalkan SSH key untuk membantu proses autentikasi saat menghubungkan komputer dengan GitHub.
7. Latihan Student Task Planner
Di akhir materi, peserta diperkenalkan dengan proyek latihan Student Task Planner. Alur yang dijelaskan adalah: 1. Menggunakan platform berbantuan AI, seperti ChatGPT, Claude, atau Antigravity. 2. Menulis prompt untuk membuat web atau aplikasi. 3. Memasukkan proyek ke Git dengan git init. 4. Melakukan commit dan push ke GitHub. 5. Membuat perubahan pada proyek. 6. Melakukan commit dan push kembali.
